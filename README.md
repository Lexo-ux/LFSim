# LFSim

Nuevo comienzo del mundo de [LifeSim](https://github.com/Lexo-ux/lifesim), centrado en la historia. Este repositorio parte **solo del lore**: no hereda código, assets, guardados ni sistemas de simulación.

## Dirección

- **La historia primero.** Lo que se juegue existe para contar la historia del mundo del Umbral, no para simular una vida completa.
- **Vida diaria mínima.** La rutina (estudios, trabajo, dinero, vivienda) aparece solo cuando importa para la historia. No es un bucle de gestión.
- **El canon manda.** Antes de escribir o diseñar algo, consultar [`lore/`](lore/README.md) y respetar sus etiquetas.

La historia se plantea como una antología de cinco vidas escritas: ver [historia/ESTRUCTURA.md](historia/ESTRUCTURA.md). La forma concreta de jugar está por decidir; esta dirección es del proyecto, no canon.

## Estructura

```text
lore/        Canon del mundo: World Bible, documentos especializados, reglas y glosario
historia/    Diseño de la historia (propuestas, no canon)
AGENTS.md    Reglas para quien trabaje en el repositorio (personas y agentes)
```

Empezar por [lore/README.md](lore/README.md) (jerarquía y etiquetas), [lore/WORLD_BIBLE.md](lore/WORLD_BIBLE.md) y [lore/CANON_RULES.md](lore/CANON_RULES.md).

## Origen

`lore/` se extrajo de `Lexo-ux/lifesim` (`main` en `cb18d42`) conservando el historial de sus commits. Los enlaces a documentos técnicos (`docs/…`) apuntan a ese repositorio; las menciones a Tasks y a «V3» describen la implementación de LifeSim, no de LFSim.

## Repositorio público

Todo lo que se suba aquí es visible para cualquiera. Los giros y respuestas marcados como RESERVED no se escriben en este repositorio.
